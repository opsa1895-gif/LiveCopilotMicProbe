# Тестова матрица — Mic Probe

Записвай резултат за всеки реален телефон. Един успешен тест не е достатъчен за продукт.

| Телефон | Android | TikTok версия | Built-in mic | Bluetooth mic | TikTok чува | Overlay чува | clientSilenced | Бележки |
|---|---:|---|---|---|---|---|---|---|
| | | | | | | | | |

## Минимален набор

- Pixel / чист Android.
- Samsung Galaxy.
- Xiaomi/Redmi/POCO.
- Android 10/11 устройство, ако имаме достъп.
- Актуален Android 15/16/17 клас устройство.
- Built-in microphone.
- Bluetooth earbuds/headset.
- TikTok Live с камера отпред и отзад.

## Критерий за успех на този етап

За дадена конфигурация считаме теста за добър само ако:

1. TikTok реално предава гласа към зрител/replay.
2. Overlay-ят едновременно показва нормални ненулеви dBFS стойности при говор.
3. `isClientSilenced()` остава false по време на говор.
4. Няма прекъсвания при заключване/отключване на ориентация, notification shade или смяна на камерата в TikTok.
5. Поне 10 минути непрекъснат тест минават без загуба на capture.
